# Public demo script

Target duration: 2 minutes 45 seconds to 2 minutes 55 seconds. Use CJ's normal voice. Do not add music.

## 0:00 to 0:15

"Finding a room means choosing how you will live with other people. That decision is usually split across filters, tabs, notes, and messages. I built one page where a person and their browser agent can work through it together."

Show the clean initial Matchboard. Let the six living cards and empty room slots explain the flow before opening a technical panel.

## 0:15 to 0:30

Open the site-tools panel and show the five tools. Keep the five-step rail visible beside the page.

"The page gives the browser a small set of WebMCP tools. The agent can use the app's real state instead of guessing where to click."

## 0:30 to 1:05

Use the sample prompt. Show `get_living_context` lighting the first step, then `stage_living_brief` moving the living cards into the brief tray. Pause on the proposal.

"The agent can stage my brief, but it cannot apply it. I can check or edit every field first."

Click **Use this brief** yourself.

## 1:05 to 1:40

Show `find_compatible_rooms` dealing three room cards onto the table, then `compare_shortlist` snapping two onto the decision line.

"CoHabby returns synthetic rooms and the practical reasons behind each result. The agent does not invent a compatibility score, and protected traits never enter the search."

Pause on the decision board.

## 1:40 to 2:15

Show `prepare_introduction`, the chosen room card, and the full draft side by side.

"The agent prepares an introduction from facts already on the page. It still cannot send anything."

Click **Confirm demo introduction** yourself and show the receipt.

## 2:15 to 2:40

Show one `registerTool` definition, one `additionalProperties: false` schema, the registration abort controller, the microphone-denying header, and the human-only confirmation action.

"The tools use strict schemas, clean up with abort signals, and update the same state as the human interface. The data is synthetic, the source is public, and the app has no model or production connection."

## 2:40 to 2:52

Return to the finished page.

"This is CoHabby Living Decision Room. The agent can do the sorting. I still make the calls."

## Edit notes

Use HyperFrames only after recording the real submitted build. Add a short title card, restrained tool-name labels, focus crops, and accurate captions. Do not add generated product footage, music, a microphone control, or a claim that the site accepts voice.
