# Asset provenance

The challenge app uses no photos, video, map imagery, resident likenesses, listing media, or production CoHabby assets.

| Asset | Source and rights | Use |
| --- | --- | --- |
| CoHabby text name and challenge doorway mark | The name is owned by CoHabby. The SVG doorway mark was drawn in this repository from the public Craft Era colors with the founder's permission. | Header identity, favicon, and selected-room transition |
| Outfit font | Google Fonts, SIL Open Font License 1.1, bundled at build time by `next/font` | Headings, labels, and buttons |
| Lucide icons | `lucide-react`, ISC License | Interface icons |
| Motion for React | `motion`, MIT License | Layout and causal state transitions |
| Synthetic room copy | Written for this repository | Demo fixtures and room cards |
| Synthetic room illustrations | Original inline SVG authored in this repository | Abstract room-card art with no real property or resident |

Two Higgsfield concept frames were generated for temporary design critique and kept outside the repository. They are not deployed assets. The public demo video is not part of the repository. It contains the submitted app, native browser tool evidence, and founder narration without music.
